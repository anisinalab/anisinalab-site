  index.html              главная страница (с тестом-диагностикой и счётчиком Метрики)

На всех пяти HTML-страницах уже стоит счётчик Яндекс Метрики № 112880124.

КАК ЗАГРУЗИТЬ НА GITHUB
  1. Распакуйте архив на компьютере (загружать нужно файлы, а не сам архив).
  2. GitHub -> репозиторий anisinalab-site -> Add file -> Upload files.
  3. Перетащите все 6 файлов -> Commit changes.
  4. Через 1-10 минут откройте сайт и нажмите Ctrl+F5.

НЕ ТРОГАЙТЕ В РЕПОЗИТОРИИ
  photo.jpg, CNAME, README.md (их нет в архиве, они у вас уже загружены).
  Если в репозитории остались kod-otnosheniy.html или diagnostic.html, их можно удалить.

КАК ПРОВЕРИТЬ СЧЁТЧИК МЕТРИКИ
  1. На странице metrika.yandex.ru нажмите «Проверить счётчик» (не раньше, чем сайт обновится).
  2. Или откройте сайт и в самой Метрике посмотрите отчёт «Онлайн» (в реальном времени).

КАК ОТКРЫТЬ И ЗАКРЫТЬ ЗАПИСЬ НА КОНСУЛЬТАЦИЮ
  GitHub -> файл site-config.js -> значок карандаша -> строка
  consultationOpen: false,   (запись закрыта)
  consultationOpen: true,    (запись открыта)
  -> Commit changes -> через 1-10 минут Ctrl+F5.
  Клуб и лист ожидания включаются строкой clubOpen: true/false.
